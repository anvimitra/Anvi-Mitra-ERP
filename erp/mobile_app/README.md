# Anvi Mitra Unified School App

One mobile app per school, with role-based access after login.

## Roles

- Principal / Admin
- Teacher
- Accountant / Office Staff
- Parent
- Student
- Driver

## Current foundation

- Flutter project scaffold
- Environment-based API URL
- Unified login shell
- Role-aware home module list
- Shared token persistence
- ERP API dashboard service
- Parent overview, notifications and linked-student API clients

## Run

```bash
flutter pub get
flutter run --dart-define=API_BASE_URL=https://YOUR-ERP-API
```

The APK is not generated by the repository changes alone; build it on a Flutter-capable machine/CI environment.
