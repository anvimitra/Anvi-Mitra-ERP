How this works

Online PostgreSQL remains the source of truth. Devices keep a local cache/outbox, push queued changes after reconnect, then pull newer server changes. Conflicts stay visible for administrator resolution.

The local connector is bound to localhost on the school computer and uses a separate connector token; it is not an open internet file server.
