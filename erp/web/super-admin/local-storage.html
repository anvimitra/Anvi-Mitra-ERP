How this works

The online PostgreSQL database remains the source of truth. The desktop connector gets a restricted folder path, reads/writes only inside that configured folder, and pulls the ERP sync journal while the machine is online. Offline web/mobile changes stay in the client outbox and sync automatically when connectivity returns.

For a real PC connection, run the included erp/local_connector/agent.js on the school computer.
