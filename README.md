# LSK Secondary School Website

Ready for GitHub Pages. Upload the contents of this repository to the `main` branch.

## Image folders
- `images/logo/` — school logo
- `images/hero/` — homepage hero background
- `images/about/` — school/about image
- `images/principal/` — principal image
- `images/admission/` — admission-section background
- `images/gallery/` — any number of gallery images

The website automatically reads images from these folders. You can replace/add gallery images without editing `index.html`.

Supported: JPG, JPEG, PNG, WEBP, GIF, AVIF.

## GitHub Pages
GitHub → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
